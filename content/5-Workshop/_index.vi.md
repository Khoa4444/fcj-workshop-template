## AI Coding Agent Risk Scoring trên AWS

Workshop này tái hiện project theo thứ tự có kiểm soát: chuẩn bị → data → S3 → Processing → Training/HPO → Pipeline/Registry → endpoint/API → monitoring → cleanup. Các command AWS tạo resource có phí được đánh dấu rõ. Chỉ chạy chúng khi đã chuẩn bị cleanup owner và thời gian demo.

## Các phần trong workshop

1. Tổng quan và ranh giới evidence.
2. Chuẩn bị local/AWS và safety gate.
3. Kiến trúc, feature contract và data flow.
4. Tạo trajectory dataset, kiểm tra local, upload S3.
5. SageMaker Processing.
6. Training, evaluation và HPO.
7. Pipeline và Model Registry governance.
8. Endpoint, Lambda và API Gateway.
9. End-to-end test và ảnh minh chứng.
10. Monitoring/cost control.
11. Cleanup bắt buộc.
