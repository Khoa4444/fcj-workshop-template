# Event Participation Report: “Agent Forge - Deepdive Day 1”

## 1. Event information

- **Event name:** Agent Forge - Deepdive Day 1
- **Time:** 09:00–12:00, 1 August 2026
- **Location:** Bitexco Financial Tower, 02 Hai Trieu Street, Saigon Ward, Ho Chi Minh City
- **Role:** Attendee
- **Event page:** [Luma – Agent Forge - Deepdive Day 1](https://luma.com/7lfn4vdv)

## 2. Overview

Agent Forge - Deepdive Day 1 focused on becoming familiar with Amazon Bedrock AgentCore and the foundational components for bringing a basic agent into a runnable environment. The programme combined a service introduction with hands-on work to deploy an agent, connect tools and Knowledge Bases, and build a web interface with authentication.

## 3. Key content from Day 1

### 3.1. Introduction to Amazon Bedrock AgentCore

The first session introduced Amazon Bedrock AgentCore and the components required to operate an agent on AWS. Three concepts were emphasized:

- **Runtime:** the execution environment for deploying and operating an agent.
- **Gateway:** the connection and control layer through which an agent accesses external tools or services.
- **Identity:** the identification and authentication mechanism used to protect resources and control access.

This session established an important foundation before the lab: an agent is not only a model that generates responses; it also needs a suitable runtime, tool connectivity, and identity mechanism to operate in a real application.

### 3.2. Hands-on Lab: setting up a basic agent

The Day 1 hands-on segment was scheduled for 10:00–11:00 and focused on three activities:

1. Deploying a basic agent in AgentCore.
2. Connecting the agent to external tools and Knowledge Bases.
3. Building a Web UI and integrating Amazon Cognito authentication.

Together, these activities showed a foundational agent-building flow: from an agent that can run, to one that can use knowledge sources and tools, and then to an interface through which authenticated users can interact with it.

## 4. Knowledge and experience gained

- An understanding of the role of Amazon Bedrock AgentCore in supporting agent deployment on AWS.
- Awareness of Runtime, Gateway, and Identity as foundational components when designing an agent system.
- A clearer view of connecting an agent to tools and Knowledge Bases instead of relying only on the model’s content-generation ability.
- Recognition that a Web UI and Amazon Cognito user authentication are important when bringing an agent closer to end users.
- An understanding of a step-by-step agent-building process, from foundations and agent setup to tool connectivity and a complete user experience.

## 5. Possible applications

From Day 1, I can apply a step-by-step approach to agentic-AI projects: first define the runtime, tool connections, and identity mechanism, then develop the user interface and interaction flow. For AWS projects, I can consider Amazon Cognito early as a component for protecting the agent-user experience rather than adding authentication only at the final stage.

## 6. Personal reflection

Day 1 offered a practical starting point for building agents on AWS. I appreciated how the programme combined concepts with a clear hands-on path, from deploying a basic agent to connecting knowledge, tools, and an authenticated interface.
